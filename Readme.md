# ESP32-S3 多功能GPS性能分析设备

## 软件需求规格说明书（SRS）v2.2

-----

## 1\. 项目目标

本项目旨在基于 `ESP32-S3FH4R2` 微控制器，从零开始打造一款多功能、高性能的GPS性能分析设备。该设备集成了**自行车码表**、**GPS轨迹记录仪**和\*\*汽车性能测试盒（P-Box）\*\*三大核心功能，旨在为骑行和驾驶爱好者提供精确、丰富的实时数据和性能分析工具。

**关键器件:**

  * **主控芯片:** `ESP32-S3FH4R2`
  * **GNSS:** `MAX-F10S` / `ATGM336H`
  * **传感器:** `LSM6DSR` (`0xD5`)X，Z轴反向，Y不变、`LIS2MDL` (`0x3D`)X，Y轴交换后Y轴反向，Z轴反向、`BMP388` (`0xED`)

-----

## 2\. 核心功能实现

我们成功实现了所有预定目标，最终交付的固件包含以下关键功能：

  * **多模应用系统:**

      * **自行车码表模式:** 实时显示速度、海拔、累计里程、坡度等关键骑行数据。
      * **汽车P-Box模式:** 用于性能测试，如0-100km/h加速，通过传感器融合（IMU加速度+GPS速度）实现精确的自动启停计时。
      * **GPS轨迹记录:** 用于记录骑行或徒步时的GPS轨迹，记录时显示GPS信息、速度信息、海拔、累计里程、气压信息、地磁方向信息。

  * **高级用户界面 (UI):**

      * 基于 `LVGL` 图形库构建，界面美观、流畅，并支持多屏幕切换。
      * 包含一个常驻的状态栏，实时显示GPS信号、SD卡状态、电池电量及充电状态。

  * **GPS轨迹记录:**

      * 通过长按按键控制记录的开始与停止。
      * 以标准的 GPX 格式将轨迹数据保存到SD卡，兼容各大运动平台。
      * GPX文件中通过扩展标签额外记录了温度、G值等丰富数据。

  * **完整的硬件驱动:**

      * 为所有外设（`ST7789`显示屏、`LSM6DSR`、`LIS2MDL`、`BMP388`传感器、GPS模块、SDIO卡槽、旋转编码器）编写了稳定、模块化的驱动。

  * **传感器校准:**

      * 实现了加速度计和磁力计的运行时校准功能。
      * 校准数据被永久保存在ESP32的 **NVS（非易失性存储）** 中，设备重启后自动加载。

  * **详细的诊断日志:**

      * 实现了专业的启动日志系统，在设备启动的前5秒内详细报告所有硬件的连接状态和关键读数，之后切换为低频心跳日志。
      * 输出内容包含三传感器温度（MCU/IMU/气压计）、IMU线性加速度和重力分量。

-----

## 3\. 技术架构

  * **开发环境:** PlatformIO
  * **核心框架:** Arduino `ESP32-S3FH4R2`
  * **UI:** `LVGL` (图形库) + `LovyanGFX` (显示驱动)
  * **核心组件:**
      * **显示:** 通过高速SPI驱动 `ST7789` LCD。
      * **存储:** 通过4-bit SDIO模式高速读写SD卡。
      * **输入:** 通过GPIO中断精确捕捉按键事件。通过PCNT捕获旋转编码器的旋转。
  * **代码结构:**
      * 采用了高度模块化的设计，将硬件驱动、UI和应用逻辑完全解耦，并通过一个中央 `config.h` 文件管理所有硬件定义，具有极佳的可维护性和可移植性。

### 5.2 功能需求

  * **F-CORE-01:** 系统提供自行车码表、GPS轨迹记录仪、汽车性能测试盒三大模块。
  * **F-CORE-02:** 码表模式下可调用GPS轨迹记录。
  * **F-CORE-03:** 系统提供设置界面模块。
  * **F-SYS-01:** 启动时RTC时间设置为固件编译时间。
  * **F-SYS-02:** 获取有效GPS时间后自动同步RTC。
  * **F-SYS-03:** RTC同步完成后屏幕显示“时间已同步”提示2秒。
  * **F-SYS-04:** **(新增)** 配置GNSS模块（例如设置刷新率F-SET-02）时，系统必须解析GPS模块返回的ACK/NACK响应，以确认配置是否成功应用。
  * **F-SYS-05:** **(新增)** 关键操作阈值（例如F-PBOX-02中的0.15G）应参数化，并移至设置菜单（F-CORE-03）中，允许用户自定义。
  * **F-UI-01:** 用户界面基于 `LVGL` 构建。
  * **F-UI-02:** 所有主功能界面共享顶部状态栏。
  * **F-UI-03:** 状态栏显示：GNSS卫星数、SD卡状态、电池百分比、充电状态。
  * **F-UI-04:** **(新增)** UI代码应进行重构，将每个主功能屏幕（例如码表、P-Box、轨迹记录）拆分为独立的源文件（.cpp/.h）以提高模块化。
  * **F-INPUT-01:** 响应旋转编码器旋转、短按、中按、长按事件。
  * **F-INPUT-02:** 主界面操作：短按切换模式，中按启停轨迹记录，长按进入设置界面。
  * **F-INPUT-03:** 按键消抖100ms，短按\<1s，中按1\~3s，长按\>3s。
  * **F-BC-01:** 自行车码表界面显示速度(km/h)、海拔(m)、本次骑行累计里程(km)。
  * **F-LOG-01:** GPS轨迹记录功能写入SD卡 `/GPX/`，支持GPX扩展数据。
  * **F-PBOX-01:** 汽车性能测试盒提供0-100km/h加速测试。
  * **F-PBOX-02:** 加速计时条件：速度\<1km/h 且 纵向加速度\>0.15G。
  * **F-SET-01:** 设置界面提供传感器校准流程。
  * **F-SET-02:** 设置界面可配置GNSS刷新率（1/5/10/25Hz）。
  * **F-SET-03:** 设置界面可配置GNSS星座。
  * **F-SET-04:** **(新增)** 传感器校准流程（F-SET-01）应在独立的FreeRTOS任务中异步执行，以避免阻塞主UI线程。
  * **F-DIAG-01:** 启动后前5秒，每10秒输出一次硬件自检状态。
  * **F-DIAG-02:** 自检报告包含：GNSS、IMU（线性加速度+重力）、磁力计、气压计、三传感器温度（MCU/IMU/气压计）。
