项目总结 (Project Summary)
1. 项目目标 本项目旨在基于 ESP32-S3FH4R2 微控制器，从零开始打造一款多功能、高性能的GPS性能分析设备。该设备集成了自行车码表、GPS轨迹记录仪和汽车性能测试盒（P-Box）三大核心功能，旨在为骑行和驾驶爱好者提供精确、丰富的实时数据和性能分析工具。关键器件有主控芯片ESP32-S3FH4R2，集成 GNSS (MAX-F10S / ATGM336H)，传感器 (LSM6DSR(0xD5)、LIS2MDL(0x3D)、BMP388(0xED)

2. 核心功能实现 我们成功实现了所有预定目标，最终交付的固件包含以下关键功能：

多模应用系统:
自行车码表模式: 实时显示速度、海拔、累计里程、坡度等关键骑行数据。
汽车P-Box模式: 用于性能测试，如0-100km/h加速，通过传感器融合（IMU加速度+GPS速度）实现精确的自动启停计时。
GPS轨迹记录:用于记录图骑行或徒步时的GPS轨迹，记录时显示GPS信息，速度信息，海拔，累计里程，气压信息，地磁方向信息
高级用户界面 (UI):
基于 LVGL 图形库构建，界面美观、流畅，并支持多屏幕切换。
包含一个常驻的状态栏，实时显示GPS信号、SD卡状态、电池电量及充电状态。
GPS轨迹记录:
通过长按按键控制记录的开始与停止。
以标准的 GPX 格式将轨迹数据保存到SD卡，兼容各大运动平台。
GPX文件中通过扩展标签额外记录了温度、G值等丰富数据。
完整的硬件驱动:
为所有外设（ST7789显示屏、LSM6DSR、LIS2MDL、BMP388传感器、GPS模块、SDIO卡槽、旋转编码器）编写了稳定、模块化的驱动。
传感器校准:
实现了加速度计和磁力计的运行时校准功能。
校准数据被永久保存在ESP32的**NVS（非易失性存储）**中，设备重启后自动加载。
详细的诊断日志:
实现了专业的启动日志系统，在设备启动的前5秒内详细报告所有硬件的连接状态和关键读数，之后切换为低频心跳日志。

3. 技术架构
开发环境: PlatformIO
核心框架: Arduino ESP32-S3FH4R2
UI: LVGL (图形库) + LovyanGFX (显示驱动)
核心组件:
显示: 通过高速SPI驱动ST7789 LCD。
存储: 通过4-bit SDIO模式高速读写SD卡。
输入: 通过GPIO中断精确捕捉按键事件。通过PCNT捕获旋转编码器的旋转
代码结构: 采用了高度模块化的设计，将硬件驱动、UI和应用逻辑完全解耦，并通过一个中央 config.h 文件管理所有硬件定义，具有极佳的可维护性和可移植性。

代码审查报告 (Code Review)
1. 优点 (Strengths)

架构清晰: 项目的模块化设计是最大的亮点。每个硬件对应一个驱动模块（.h/.cpp），职责单一，代码内聚性高。
关注性能: 在关键路径上使用了高效的技术，例如LVGL的DMA缓冲区、SD卡的SDIO模式、编码器的中断读取，这些都是专业嵌入式开发的体现。
健壮性: 代码中包含了充分的错误检查和状态反馈。例如，sensors_init 会独立报告每个传感器的状态，GPS模块有超时检测，日志系统能明确指出哪个硬件“not present”。
可配置性: config.h 的使用使得固件可以轻松适配不同的硬件引脚布局，极大地提高了代码的可移植性。
代码质量: 代码风格统一，注释清晰，遵循了良好的嵌入式C++实践。
2. 未来可改进点 (Areas for Future Improvement)

UI代码组织: 随着功能增加，ui.cpp 文件逐渐变得庞大。可考虑将每个主屏幕的UI创建逻辑拆分到独立的文件中（如 ui_settings.cpp），以进一步提升代码组织性。
异步操作: 当前的传感器校准流程是阻塞式的，会短暂冻结UI。在未来的版本中，可考虑将其放入一个独立的FreeRTOS任务中执行，以改善用户体验。
GPS配置健壮性: 当前的GPS配置是单向的（仅发送命令）。一个更完整的实现应包括解析来自GPS的ACK/NACK响应，以确认配置是否成功应用。
参数化: 应用逻辑中的一些阈值（如P-Box的启动加速度、码表的自动暂停速度）目前是硬编码的。将这些值移至 config.h 或设置菜单中，可以提高固件的灵活性。

F-UI-02	所有主功能界面需共享一个顶部状态栏。

F-INPUT-01	系统需响应旋转编码器的旋转、短按、长按、双击四种独立事件。

F-PBOX-01	汽车性能测试盒界面需提供0-100km/h加速测试功能。
F-PBOX-02	加速测试的计时器需在“车辆速度低于1km/h”且“纵向加速度超过0.15G”的复合条件下自动开始。
F-SET-01	设置界面需提供一个入口，以启动传感器（加速度计+磁力计）校准流程。
F-SET-02	设置界面需提供一个子菜单，允许用户设置GNSS模块的数据刷新率（1Hz, 5Hz, 10Hz，25Hz）。
